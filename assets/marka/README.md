# Protyp marka dosyaları

- `logo.svg`, `logo-1024.png`, `logo-2048.png`: ikon + yazı (yatay, 2:1)
- `icon.svg`, `icon-512.png`, `icon-1024.png`: yalnızca ikon (kare)

Renkler: yazı moru `#6D28D9`, vurgu zümrüdü `#059669`, mürekkep `#1E293B`, kâğıt `#FFF8EE`.
Stil: el çizimi ampul + yıldız kıvılcımlar. Ampulün etrafına ışın demeti eklenmez (siyasi logo çağrışımı nedeniyle bilinçli olarak çıkarıldı).
